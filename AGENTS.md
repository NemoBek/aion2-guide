# Инструкции для Codex

## Цель проекта

Поддерживать понятный русскоязычный интерактивный гайд для нового игрока Aion 2. Сайт должен оставаться быстрым, наглядным и пригодным для бесплатного публичного размещения.

## Приоритеты

1. Не ломать существующие чек-листы, вкладки, галереи, навигацию и сохранение прогресса.
2. Сохранить текущий визуальный стиль: тёмная игровая тема, голубые и золотые акценты.
3. Сначала показывать практический следующий шаг игрока, а не длинные вступления.
4. Не возвращать удалённую рекламу, контакты, макросы, временные анонсы серверов и повторы из таблицы.
5. Любые автоматически полученные данные считать недоверенными: валидировать структуру и экранировать текст.

## Источник

Опубликованная Google-таблица:

`https://docs.google.com/spreadsheets/d/e/2PACX-1vQ0C3iKFteGvIbgqNDnQq7bmwIaU23DvjbPa0HPSVAdOOiCeBkEq69Cn8jVMJhToJcztCRylYeTYfOk/pubhtml`

Не изменять исходную таблицу. Сайт только читает публичные данные.

## Хранение данных

- Прогресс пользователя хранить только локально в браузере.
- Не добавлять регистрацию, базу данных, аналитику или платные сервисы без прямого запроса пользователя.
- Последний валидный снимок данных должен оставаться в репозитории, чтобы сайт работал, если Google временно недоступен.

## Автоматическое обновление

- Вынести содержимое гайда из `app/page.tsx` в типизированный слой данных.
- Создать отдельный синхронизатор, который скачивает опубликованную таблицу, извлекает только разрешённые разделы и формирует проверенный снимок JSON.
- При ошибке парсинга не публиковать повреждённые данные и не удалять предыдущий снимок.
- Добавить дату последней успешной синхронизации.
- Новые изображения скачивать в локальные ресурсы репозитория, проверять тип и разумный размер файла.
- Не вставлять произвольный HTML из таблицы в страницу.

## Публикация

Целевой вариант — GitHub Pages и GitHub Actions в публичном репозитории. Решение должно быть бесплатным и не требовать сервера. Учесть базовый путь вида `/aion2-guide/` для ресурсов и ссылок.

## Проверка перед завершением

- сборка проходит без ошибок;
- главная страница открывается на корневом URL GitHub Pages;
- изображения работают с базовым путём проекта;
- интерфейс пригоден на ширине 360 px и на большом экране;
- прогресс сохраняется после перезагрузки;
- автоматическая синхронизация не публикует невалидный результат;
- в футере сохранены ссылка на оригинал, указание на неофициальный характер сайта и дата обновления.
