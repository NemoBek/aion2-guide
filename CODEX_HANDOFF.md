# Состояние проекта Aion 2

## Готово

- Сайт сохранён как Next.js-приложение с полностью статическим экспортом в `out/`.
- Для GitHub Pages настроен базовый путь `/aion2-guide/` через `pnpm build:pages`.
- Контент страницы вынесен в типизированный слой `data/guide.ts` и проверяемый снимок `data/guide.snapshot.json`.
- `pnpm sync` читает опубликованные CSV и HTML выбранных вкладок Google-таблицы, обновляет подтверждённые позиции раннего фарма, ссылки на билды и локальные изображения маршрута, механик и тир-листов.
- Добавлены разделы по сбору и крафту и тир-листам. Текст крафта редактируется вручную; иллюстрации тир-листов сверены с опубликованной таблицей.
- Нераспознанная структура, новый текст фарма, неизвестный URL или ошибка изображения останавливают синхронизацию. Предыдущий снимок остаётся в репозитории.
- `.github/workflows/pages.yml` собирает и публикует сайт после проверки, а по расписанию и вручную сначала синхронизирует данные.
- Футер содержит источник, неофициальный статус, предупреждение о возможных изменениях игры, согласованные ссылки автора TitanTheF и дату обновления данных.
- Старая конфигурация хостинга и базы данных удалена из проекта.

## Проверено локально

- `pnpm install --frozen-lockfile` и `pnpm build:pages` проходят.
- Статический экспорт содержит ресурсы с префиксом `/aion2-guide/`.
- Проверка в браузере на ширинах 360 и 1440 px не выявила горизонтального переполнения.
- Чек-лист сохраняется после перезагрузки, вкладки переключаются.
- Повторная синхронизация неизменной таблицы не меняет снимок. При недоступной сети синхронизация завершается с ошибкой, а хеш снимка остаётся прежним.

## Ограничение синхронизации (подробности)

Таблица оформлена как визуальный документ, поэтому её текст нельзя целиком безопасно сопоставить карточкам сайта. Неподтверждённые изменения требуют редакторской проверки. Галереи классов остаются локальными и не синхронизируются автоматически, чтобы не вернуть исключённые макросы.
